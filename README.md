# Finance Checker

Finance Checker is a personal budgeting app. It runs only on my own computer
and connects only my own bank accounts through Plaid. It has no other users.

## What it does
- Shows my account balances, monthly spending by category, and recent transactions.

## Privacy
- Data is used only to show me my own finances. It is never sold or shared.
- Bank data and Plaid access tokens are stored only on my computer, which uses
  full-disk encryption.
- The app does not run on any public server and cannot be reached from the internet.
- Disconnecting a bank in the app removes it from Plaid and deletes its data
  from my computer.
